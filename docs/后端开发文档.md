# HonoCareer 面试后端开发文档

实现遵循 `api → services → agent/llm/db`。面试依赖的账号、画像和简历已实现；答辩相关占位文件保留供其他成员开发。无需新增 schemas/core/uploads 等目录，DTO/VO 位于 `app/api/contracts.py`，文件内容存在 SQLite 内，解析器只接收字节。

## 启动和模型

Python 3.12。按根目录 README 安装 `requirements.lock.txt` 后启动。应用入口 `app.main:app`；本地练习界面 `/`，Swagger `/docs`，ReDoc `/redoc`，运行时Schema `/openapi.json`，健康检查 `/health`。

`Settings.from_env()` 读取 `.env`；生产环境配置独立 JWT_SECRET、DeepSeek API Key 及精确CORS来源。开发未设置 JWT_SECRET 时，在数据库父目录写入一次随机密钥供本机重启后继续验证登录；不提交该文件。默认provider=deepseek，缺Key会明确报错。只有显式 LLM_PROVIDER=demo 才使用规则演示；UI和报告均标注。

DeepSeek使用服务端HTTP流适配，关键字段参考[官方Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/)。模型原始错误、prompt、用户完整对话、密钥和口令不写日志。模型供应商接收进行面试所需的画像、已确认简历、JD及用户回答。

## 持久化和任务

`app/db/models.py` 定义表、外键与索引；`app/db/session.py` 使用短事务、WAL和busy timeout。用户鉴权与数据查询都以服务端令牌主体隔离。messages.seq 在事务内分配，单会话未完成响应有唯一索引。创建幂等键及请求哈希保存在数据库，clientSessionId/clientMessageId另有唯一约束。

`Orchestrator` 由lifespan启动，最多4个并行任务，持久查询 queued 的 responses/reports/resumes。模型调用不持有数据库锁；SSE只读events，不拥有生成任务。取消后即使远端模型仍短暂返回数据，状态检查也禁止继续提交消息和事件。报告与简历任务在重启后重新排队；中断的流式消息明确失败，供新clientMessageId重试，避免不知情地再次推进阶段。

当前只支持**单个应用进程和一个uvicorn worker**。多进程部署前需用带租约/心跳的任务队列替换启动恢复逻辑，并配置共享限流器。SQLite和文件体积限制适合课程项目及单实例联调；不要直接把当前队列横向扩容。

## Agent与评分

- `state_machine.py` 控制六阶段；经历、情景阶段对证据不足的回答最多追加一次追问。
- `question_bank.search` 从真实本地策划题库按场景/阶段和关键词排序检索；`job_description.retrieve` 只提取用户提供的JD，不声称联网抓取岗位。
- `prompts.py` 将材料视为不可信资料，与系统规则分离；业务允许调用的工具固定，不执行模型任意工具名。
- `llm/base.py` 是统一provider协议；deepseek是真实云端流调用，demo仅用于离线验证。
- `scorecard.generate` 校验四维枚举、分值与消息证据，由服务端计算等权综合分。没有回答时明确证据不足，错误评分不入库。

## 客户端接入

基地址 `/api/v1`；HttpClient携带Bearer、Idempotency-Key。SseClient通过fetch/原生HTTP流读取，并持久记录eventId；断线使用Last-Event-ID，不能重新POST原回答来模拟续传。若提交结果未知，用相同clientMessageId和相同内容重试，拿回同一responseId；若已明确生成失败，用户主动重试用新的clientMessageId。

`GET /sessions/{id}` 的 activeResponseId 允许重开页面后找到未完成任务。message_delta.offset按Unicode码点计算，message_completed和GET消息列表负责最终对齐。每页消息按seq正序，cursor向更早内容翻页。

附带的Web界面用于后端联调和演示，未替代ArkUI-X客户端。支持三类场景、画像创建、简历解析人工核对、流式对话、报告证据、弱项、记忆、离线缓存与记录导出。浏览器sessionStorage保存当前会话令牌；localStorage按userId隔离缓存；退出登录清理当前账号作用域缓存。源代码不使用外部CDN，浏览器用户内容经过转义。

## 验证和范围

运行 `python -m pytest -q`。覆盖三场景完整面试、阶段推进、幂等冲突、并行提交、SSE重放、取消、重启恢复、错误模型输出、伪造评分证据、令牌轮换和退出、跨账号隔离、简历确认与快照、分页、记忆开关/清除、级联删除、请求体限制及OpenAPI引用完整性。

真实DeepSeek线上端到端调用需要项目方API Key；自动化使用注入provider与HTTP MockTransport验证协议，不消耗真实模型额度。扫描件OCR、答辩实现、鸿蒙真机ASR/TTS及三端编译不属于本次已验证的面试后端。
