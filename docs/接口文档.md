# HonoCareer 面试后端接口文档

版本 1.0，2026-10-21。依据飞书 v2.0 接口草案及开发文档实现求职、志愿者、社团面试。完整字段、必填项与响应类型见同目录 `openapi.json` 或运行服务后的 `/docs`。答辩属于独立模块，本次不注册答辩接口，`mode=defense` 不会落入面试流程。

原始资料：[接口草案](https://my.feishu.cn/wiki/DgqCw8gzFioFfak83WCcOa56nQh)、[需求](https://my.feishu.cn/wiki/VoPfwWgTpiCwXckDABAceD6un8s)、[开发约定](https://my.feishu.cn/wiki/SoUzw7x5HiJKwSktT55cm6urnrg)。

## 全局约定

- 基础路径 `/api/v1`，以飞书接口约定为准，修正旧 README 的无版本前缀说明。
- 除注册、登录、刷新令牌外，全部接口携带 `Authorization: Bearer <accessToken>`，退出登录同样需要鉴权。
- JSON 成功响应四项必填：`{code:0,message:"ok",data:T,requestId:string}`。删除接口的 `data` 为 null。
- 失败响应：`{code:string,message:string,requestId:string,details?:[{field,reason}]}`。响应头 `X-Request-ID` 与响应体一致。认证令牌、密码与原始模型错误不会进入响应或日志。
- JSON 请求为 `application/json`；上传由客户端生成含 boundary 的 multipart Content-Type。
- 日期时间均为含 UTC 时区的 ISO 8601 字符串。ID 为不透明字符串；不能使用客户端 userId 作为鉴权依据。
- 创建画像、简历、会话必须带 `Idempotency-Key`，长度 8～120。同一账号和资源类型中，同键同请求返回原资源；同键不同内容返回 409。
- 所有列表统一返回 `data:{items:T[],nextCursor:string|null,hasMore:boolean}`。请求参数 `cursor?`、`limit?`，默认20，范围1～50。游标绑定账号、资源与过滤条件，不可混用。画像/会话/简历按更新时间和ID倒序；弱项/记忆按创建时间和ID倒序。会话消息先取最新一页，每页内部按 seq 正序排列；下一页获取更早消息，前端应前插。
- PATCH 至少包含一个可修改的非 null 字段；`{}`、画像仅传 version、显式 null 都返回400。空数组可用于清除数组字段。

## 账号和用户

| 方法 | 路径 | 请求 | data |
| --- | --- | --- | --- |
| POST | /auth/register | account、password，nickname? | userId |
| POST | /auth/login | account、password、clientType? | accessToken、refreshToken、expiresIn、user |
| POST | /auth/refresh | refreshToken | 新 accessToken、refreshToken、expiresIn |
| POST | /auth/logout | 无 | null |
| GET | /users/me | 无 | userId、nickname、avatarUrl、emailMasked、createdAt |
| PATCH | /users/me | nickname?、avatarUrl? | 同上 |

当前开放账号密码自注册，可通过 `REGISTRATION_ENABLED=false` 关闭；账号不区分大小写，密码8～128字符并保留首尾空格。注册不要求验证码，未接入验证码发送渠道。clientType 为 harmonyos/android/ios/web，默认 harmonyos。Web 仅用于当前联调界面。刷新令牌轮换后旧值立即失效；退出使当前登录会话的 access/refresh 均失效。

## 面试画像

| 方法 | 路径 | 请求 | data |
| --- | --- | --- | --- |
| POST | /profiles | type、displayName、baseInfo?、detail | ProfileVO |
| GET | /profiles | type?、cursor?、limit? | Page<ProfileVO> |
| GET | /profiles/matches | mode=interview、scene、cursor?、limit? | Page<ProfileMatchVO> |
| GET | /profiles/{profileId} | 无 | ProfileVO |
| PATCH | /profiles/{profileId} | version 及 displayName?/baseInfo?/detail? | 更新后的 ProfileVO |
| DELETE | /profiles/{profileId} | 无 | null |
| POST | /profiles/{profileId}/resume-import | resumeId、selectedFields | 更新后的 ProfileVO |

`type` 和 `scene` 均为 employment/volunteer/club，且必须一致；不支持跨类型复用。创建时缺少目标方向可以保存 draft，已填则 ready。会话仍须明确提供场景目标。

`baseInfo` 可包含 name、school、department、major、degree、grade、enrollmentYear、expectedGraduationYear。

| type | detail 字段 |
| --- | --- |
| employment | targetRole、roleDirection、targetCompany、targetIndustry、expectedSalary、availableStartDate 为字符串；skills、certificates、projectExperience、internshipExperience 为 string[] |
| volunteer | activityType、availableTime、motivation 为字符串；volunteerExperience、relevantSkills 为 string[] |
| club | targetClub、clubDescription、requirements、motivation 为字符串；interests、relevantExperience 为 string[] |

字段可空但不得是未定义结构；所有长度和数组上限均在 OpenAPI 声明。PATCH detail 和 baseInfo 合并已有字段，不覆盖未传值；乐观锁 version 冲突返回 `PROFILE_VERSION_CONFLICT`。

简历导入仅用于 employment 且简历已 confirmed。selectedFields 为 education/projects/skills/certificates 的非空数组。education 导入基础资料学校/专业/学位，projects 导入 projectExperience，skills 和 certificates 分别导入同名字段；不修改未选择的部分。重复导入内容相同不会递增版本。

## 简历上下文

| 方法 | 路径 | 请求 | data |
| --- | --- | --- | --- |
| POST | /resumes | multipart file，PDF或DOCX，最多10MB | ResumeVO |
| GET | /resumes | cursor?、limit? | Page<ResumeVO> |
| GET | /resumes/{resumeId} | 无 | ResumeVO 含 parsedContent |
| GET | /resumes/{resumeId}/file | 无 | 鉴权后的原文件字节，attachment |
| POST | /resumes/{resumeId}/parse | 无 | jobId、status |
| GET | /resumes/{resumeId}/parse | 无 | status、jobId、error、解析字段 |
| PATCH | /resumes/{resumeId}/parsed-content | education?/projects?/skills?/certificates? | ResumeVO |
| POST | /resumes/{resumeId}/confirm | 无 | confirmed 的 ResumeVO |
| DELETE | /resumes/{resumeId} | 无 | null |

状态为 uploaded → queued → processing → review_required → confirmed；失败为 failed。解析失败可重复触发或手动补充再确认；确认后再次编辑会回到 review_required。解析是本地保守文本提取，不虚构缺失资料；扫描件OCR未实现，会明确失败并提示手动补充。PDF最多100页，不支持加密PDF；DOCX解压内容最多30MB。上传时验证扩展名和文件头。

`education:[{school,major?,degree?,startDate?,endDate?}]`；`projects:[{name,role?,description?}]`；skills、certificates、warnings 均为 string[]。未确认结果不可用于会话上下文或画像导入。删除原件不改变已创建会话的解析快照。

## 面试会话和消息

| 方法 | 路径 | 请求 | data |
| --- | --- | --- | --- |
| POST | /sessions | SessionCreateDTO | SessionVO 含 firstPrompt |
| GET | /sessions | mode=interview、status?、cursor?、limit? | Page<SessionVO> |
| GET | /sessions/{sessionId} | 无 | 配置、快照、阶段、报告状态、activeResponseId |
| PATCH | /sessions/{sessionId} | title?、modality? | SessionVO |
| POST | /sessions/{sessionId}/messages | clientMessageId、content，kind?、inputMode?、audioId? | userMessageId、responseId、status=queued |
| GET | /sessions/{sessionId}/messages | cursor?、limit? | Page<MessageVO> |
| POST | /sessions/{sessionId}/finish | reason=user_end/flow_complete | status、reportId |
| POST | /sessions/{sessionId}/cancel | 无 | status=cancelled、cancelledAt |
| DELETE | /sessions/{sessionId} | 无 | null |

创建示例：

```json
{
  "mode":"interview", "scene":"employment",
  "sceneConfig":{"targetRole":"后端开发工程师","jobDescription":"Python、SQL与接口设计"},
  "profileId":"prf_xxx", "modality":"text",
  "clientSessionId":"client-unique-id", "resumeId":"res_optional"
}
```

sceneConfig 对求职必填 targetRole（可选 jobDescription）；志愿者必填 activityType（可选 requirements）；社团必填 targetClub（可选 clubDescription/requirements）。不传 resumeId 表示不使用简历。会话保存画像版本与已确认简历快照。

stage 严格为 opening → self_introduction → experience_followup → situational_questions → candidate_questions → review。服务端决定推进；经历/情景阶段根据本轮是否缺少证据可额外追问一次，有界收敛。客户端不自行按消息数推断阶段。

status 为 active/generating_report/completed/failed/cancelled。finish 排队异步评分，重复结束使用同一 reportId；报告失败时可再次 finish 重试。处理消息中 finish 返回409。自然进入 review 会自动排队评分。cancel 仅适用于 active，重复取消幂等，会终止后续消息落盘，不生成报告。active/generating_report 不允许 DELETE，需先结束或取消。

消息 kind 在本模块只接收 answer；inputMode 为 text/voice，content 是用户已确认的文本。clientMessageId 同会话唯一，同ID同内容不重复保存或推进；不同内容返回409。一个会话同一时间仅允许一个未完成响应。队列独立于SSE订阅运行，断线后可从 activeResponseId 找回正在处理的响应。

## SSE 事件

`GET /sessions/{sessionId}/responses/{responseId}/events`，同样使用 Bearer 请求头。Content-Type 为 text/event-stream。浏览器应使用 fetch 流读取；原生 EventSource 不能携带自定义 Authorization，不能把令牌放进 URL。

```text
id: evt_xxx
event: message_delta
data: {"eventId":"evt_xxx","responseId":"rsp_xxx","timestamp":"2026-10-21T02:00:00+00:00","payload":{"messageId":"msg_xxx","delta":"你好","offset":0}}

```

event 是唯一事件判别值；data 不重复 type。eventId/responseId/timestamp/payload 四项必填。

| event | payload |
| --- | --- |
| queued、thinking、done | {} |
| tool_started | toolCallId、toolName |
| tool_finished | toolCallId、toolName、status=completed/failed，questionIds? |
| message_delta | messageId、delta:string、offset:int |
| stage_changed | stage |
| message_completed | messageId、content、stage |
| report_ready | reportId、sessionId |
| error | code、message、retryable:boolean |

offset 为已生成文本的 Unicode 码点位置，JS 请使用 Array.from(content) 而非 UTF-16 slice 直接计算。message_completed 为最终完整文本。error 后会有 done；若部分 delta 后出现error，不把该回答视为完成，应通过消息列表对齐已落盘记录。

事件持久化，可通过 Last-Event-ID 从该事件之后续传；ID不属于此响应返回400，属于他人响应返回404。重新订阅只补取，不触发模型调用。自然结束会在报告完成后发 report_ready 和 done；手动 finish 后通过报告接口轮询。空闲每15秒发送注释心跳。服务重启中断的生成标记 AGENT_INTERRUPTED，不自动重复提问；客户端可发新的 clientMessageId 重试。当前为单进程持久队列，请用一个 uvicorn worker。

## 报告、弱项和记忆

| 方法 | 路径 | 请求 | data |
| --- | --- | --- | --- |
| GET | /sessions/{sessionId}/report | 无 | ReportVO；未就绪返回202 REPORT_PENDING |
| POST | /sessions/{sessionId}/weak-points | dimensionKey、messageIds?、note? | WeakPointVO 含 sessionId |
| GET | /weak-points | mode=interview、cursor?、limit? | Page<WeakPointVO> |
| DELETE | /weak-points/{weakPointId} | 无 | null |
| GET | /users/me/memory-settings | 无 | enabled:boolean |
| PATCH | /users/me/memory-settings | enabled:boolean | 同上 |
| GET | /users/me/memories | cursor?、limit? | Page<MemoryVO>，含来源 sessionId |
| DELETE | /users/me/memories | 无 | null |

评分固定四维：expression_clarity/logic/role_match/adaptability，每项整数0～100，综合分为四维等权平均后四舍五入。dimensions 含 label、score、evidence:string[]、strengths:string[]、issues:string[]、suggestions:string[]；报告另含 summary、actionItems、weakPointTags、generatedAt、evaluationSource。证据必须引用本会话真实用户消息，模型格式或证据校验失败会返回503并可重试，不会静默接受虚构证据。

没有回答时返回综合分0及 insufficient_evidence，明确不可评价。demo 模式的 evaluationSource=demo，报告标注规则演示；真实云端为 deepseek。reportStatus（会话内）为 pending/ready/failed；报告资源自身 status=completed 与飞书示例一致。

弱项只能从已完成会话创建，messageIds 必须属于该会话。记忆只保存报告维度摘要，不保存用户原文、密码或验证码。关闭后既不读取历史摘要和弱项，也不新增摘要；清除摘要不删除历史。删除会话会级联清理其消息、事件、报告、弱项与记忆来源。retentionPolicy 未经产品确定，不对外提供虚构取值。

## 状态码与业务码

| HTTP | 业务码 | 含义 |
| --- | --- | --- |
| 202 | REPORT_PENDING | 先结束会话；报告生成中按 Retry-After 查询 |
| 400 | VALIDATION_ERROR | 入参、游标、空PATCH或Last-Event-ID无效 |
| 401 | AUTH_REQUIRED / AUTH_INVALID_CREDENTIALS / TOKEN_EXPIRED | 认证失败、令牌过期 |
| 403 | REGISTRATION_DISABLED | 注册未开放 |
| 404 | NOT_FOUND | 资源不存在或不属于当前账号 |
| 409 | PROFILE_VERSION_CONFLICT / SESSION_STATE_CONFLICT / RESOURCE_STATE_CONFLICT / IDEMPOTENCY_CONFLICT / ACCOUNT_EXISTS | 版本、状态、幂等或账号冲突 |
| 413 | FILE_TOO_LARGE | 空文件或超过大小限制 |
| 415 | UNSUPPORTED_FILE_TYPE | 非PDF/DOCX或文件头不匹配 |
| 422 | PROFILE_TYPE_MISMATCH / MATERIAL_NOT_CONFIRMED / INVALID_EVIDENCE | 画像、确认状态或证据不符合业务要求 |
| 429 | RATE_LIMITED | 本服务或模型限流 |
| 500 | INTERNAL_ERROR | 服务内部异常，不暴露堆栈 |
| 503 | AGENT_UNAVAILABLE | 密钥未配置、模型不可用、报告证据或格式无效 |

后台解析失败体现在简历的 failed/error；后台生成失败通过 SSE error 或报告503呈现。写接口按账号默认60次/分钟；登录/注册/刷新合计按来源20次/分钟；429响应含 Retry-After。

## 与飞书草案的修正

统一匹配/弱项/记忆分页；补简历 cursor；定义全部面试 stage 与结构化解析字段；补取消会话、原件下载和活动 responseId；定义SSE载荷及断线语义；补弱项来源；删除未接入的验证码必填项；明确记忆只开关；明确空PATCH错误。所有 Schema 均由 Pydantic 生成，引用指向真实 components.schemas，无悬空 $$ref。

按仓库 README 的职责分工，语音 ASR/TTS 由设备端适配器负责。本次面试后端不注册草案中尚未接入供应商的 /speech/*，也不伪造音频URL；保留 voice inputMode/modality 以支撑鸿蒙闭环。浏览器转写/朗读仅是能力可用时的联调辅助，鸿蒙真机语音与ArkUI-X三端编译仍由原生客户端验收。
